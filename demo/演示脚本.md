## 2. 复现环境

```bash
export PATH="/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/toolchains:$PATH"
hdc list targets        # 需出现 127.0.0.1:5555
```

## 3. 复现操作序列（hdc / uitest）

```bash
T=127.0.0.1:5555
HAP=entry/build/default/outputs/default/entry-default-unsigned.hap
hdc -t $T install -r "$HAP"
hdc -t $T shell "aa start -a EntryAbility -b com.foglight.files"

# 控件树与点击（坐标取自 1280×2832 模拟器）
hdc -t $T shell "uitest dumpLayout -p /data/local/tmp/l.json"
hdc -t $T shell "uitest uiInput click 384 2640"       # 切到「探索」页签
hdc -t $T shell "uitest uiInput swipe 640 2250 640 900 1800"   # 向下滚动
hdc -t $T shell "snapshot_display -f /data/local/tmp/shot.jpeg"
hdc -t $T file recv /data/local/tmp/shot.jpeg <本地路径>
```

真相路径的 14 次选择（按目录顺序，页面会自动更新可用选项）：

| 场景 | 依次选择的选项文字 |
|---|---|
| S1 旧馆 | 先去借阅台查记录 → 逐页核对值日证 → 翻到奖杯照片那一页 → 收进证物袋 → 先不追问，答应替她保密 |
| S2 钟楼 | 核对涂改痕迹 → 比对照片上的划痕 → 答应不把他的名字写进稿子 → 翻到送修回执 |
| S3 连廊 | 查看手动跳闸痕迹 → 导出 21:30–22:00 片段 → 沿着水迹走到连廊尽头 → 逐行比对公示名单 → 还原 21:40 的完整时间线 |

推理台：选「社长 / 改评优名单 / 21:40 人为拉闸」→ 点「验证推理条件」→ 点「提交最终判断」。

重启恢复：

```bash
hdc -t $T shell "aa force-stop com.foglight.files"
hdc -t $T shell "aa start -a EntryAbility -b com.foglight.files"
```

分支对比：结局页点「重新开局，换一种选择」→ 探索页依次选「先去借阅台查记录 → 翻到奖杯照片那一页 → 当场念给大家听 → 便签公开后，先道歉」→ 切到 S2，观察 E08 变体与 E09 锁定。

## 4. 视频生成命令

```bash
ffmpeg -y -f concat -safe 0 -i frames.txt \
  -vf "scale=506:-2,fps=25,format=yuv420p" \
  -c:v libx264 -preset veryfast -crf 23 -movflags +faststart \
  demo/雾灯档案_运行演示.mp4
```

`frames.txt` 每行 `file '<绝对路径>'` + `duration <秒>`，按上表 1–11 顺序排列，末行重复最后一帧。
