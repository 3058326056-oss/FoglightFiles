# 持续学习与更新计划：API 26 版本号变更下的状态管理 V2 迁移验证

> 目标四素材 · 撰写人：本人（独立完成） · 资料核查日期：2026-11-15
> 一个具体学习任务，配套资料核查途径与可判定的成效验证办法。

## 1. 背景：为什么要定这个任务

本工程 `build-profile.json5` 冻结为 `targetSdkVersion 26.0.0` / `compatibleSdkVersion 6.1.1(24)`。华为官方《应用兼容性说明》指出，自 26.0.0 起 API 版本号调整为语义化版本（SemVer），并给出 `26.0.0 > 6.1.1(24)` 的大小关系；《工程级 build-profile.json5 文件》说明从 API 26.0.0 起 `compatibleSdkVersion`、`targetSdkVersion` 统一为字符串。这意味着：工程在 API 24 的存量设备上仍要能跑，却按 API 26 的目标行为编译，涉及版本隔离的行为变更必须以 `targetSdkVersion` 为准。

同时，本作品在状态刷新上选择了状态管理 V1（理由见 `docs/新技术认识.md`），而 V2 的 `@ObservedV2/@Trace` 自 API 12 起已可用、V1/V2 混用接口自 API 19 起可用。两者都不缺版本能力，缺的是**在本工程的具体上下文里验证过**。因此下一步学习不是泛读文档，而是做一次可判定的迁移实验。

## 2. 具体学习任务（一个，范围可控）

**把 `DeductionView`（推理验证页）迁移到状态管理 V2，并在 API 24 与 API 26 两套目标下验证兼容判断。**

拆解为四个可交付的小步骤：

1. 把 `Hypothesis` 与推理页的校验结果封装为 `@ObservedV2` 类，对 `suspect / motive / timeline / verdictReady / verdictShown` 加 `@Trace`，`DeductionView` 改为 `@ComponentV2`，值参改 `@Param`，并在构造处按官方指导处理 V1→V2 传值。
2. 用 `deviceInfo.apiAvailable('26.0.0')` 做版本兼容保护：API 26 走新写法，低版本走现有 V1 分支；核对官方要求"版本号必须写字面量""告警消除只认单独的 if 判断"。
3. 保持 `CaseEngine` 纯逻辑层与 `CaseViewModel` 的 SSOT 不变，确保迁移只触及 UI 层，12 条 Local Unit Test 无需改写。
4. 在 `compatibleSdkVersion` 允许的范围内，分别用 API 24 兼容配置与 API 26 目标配置构建，记录行为差异。

## 4. 成效验证办法（可判定，不写空话）

| 判据 | 通过标准 | 证据形式 |
|---|---|---|
| 构建 | 迁移前后 `hvigorw assembleHap --mode module -p product=default --no-daemon` 均为 `BUILD SUCCESSFUL`，且 `build-profile.json5` 的 SDK 三项一字未改 | 构建日志文本 + `git diff build-profile.json5` 为空 |
| 回归 | 12 条 Local Unit Test 仍为 `Pass: 13, Failure: 0, Error: 0`（含模板用例） | `docs/evidence/test/test_result.txt` |
| UI 等价 | 推理页三项选中高亮、验证结果卡、提交结局，与 V1 版截图逐项一致 | 迁移前后两张 `snapshot_display` 截图对比 |
| 兼容判断 | API 24 兼容配置下不调用 26 新增能力且无崩溃；API 26 目标配置下新分支生效 | 两套构建日志 + 两套运行截图 + `deviceInfo.apiAvailable` 分支记录 |
| 可解释 | 写清「为什么该行为只在 targetSdkVersion ≥ 26 时生效」，并指出若误改 `compatibleSdkVersion` 会出现什么后果 | 一页结论笔记 |

## 6. 判断"学会了"的标准

不是"看过文档"，而是能回答三个问题并能用证据支撑：① 本工程 `compatibleSdkVersion` 为 24 时，使用 API 26 新增接口需要怎样的保护，为什么 `targetSdkVersion` 决定行为隔离？② `@ObservedV2` 类为什么必须 `new` 实例化、为什么 `@Trace` 不能单独使用？③ 把本项目 `JSON.parse` 白名单校验产生的纯数据状态迁到 V2，会在哪一步失去"零系统依赖可直接单测"的性质？三个问题都能给出"文档原句 + 本地实测"两重依据，才算完成这项学习。
